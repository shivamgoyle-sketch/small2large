# Small2Large Static Website

An original, responsive one-page agency website built with plain HTML, CSS, and JavaScript. No build step, CMS, or server is needed.

## Use it

Open `index.html` in a browser, or upload the entire folder to any static host (Netlify, GitHub Pages, Cloudflare Pages, cPanel, etc.). Keep the folder structure unchanged.

## Edit content

- Main text and links: edit `index.html`.
- Colours, layout, and responsive styles: edit `css/style.css`. Key brand colours are at the top under `:root`.
- Menu, reveal effects, counters, and footer year: edit `js/main.js`.
- Your supplied logo is now installed at `assets/images/logo.png`. Keep the same filename if you replace it later, so no HTML changes are needed.

## Contact links

WhatsApp, email, and Instagram links are already connected to the supplied Small2Large contact details. Change their `href` attributes in `index.html` if needed.

## Note about the logo

The brand blue used throughout the site is matched to the supplied logo: `#38B6FF`.
